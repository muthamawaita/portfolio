# JEREMIAH MUTHAMA WAITA Portfolio

This project is a clean personal portfolio for Jeremiah Muthama Waita. It focuses on a premium public-facing presentation without the extra dashboard, admin, or backend platform complexity.

## Purpose

- Showcase my work as a data analyst, software developer, and technical educator
- Present a premium personal brand and professional profile
- Keep the experience simple, elegant, and easy to navigate

## Stack

- Next.js
- TypeScript
- Tailwind-inspired styling

## Local development

1. Install dependencies with `npm install`
2. Run `npm run dev`
3. Open the local Next.js app in the browser

## Build check

- `npm run build`

## Notes

This portfolio is intentionally kept focused on public-facing work only, with no backend or SaaS administration layer required.
